## ⭐ Featured project — Emergency Department & Patient Flow Analytics

End-to-end healthcare analytics on 54,837 synthetic ED presentations, modelling
the metrics Australian health services actually track: **NEAT 4-hour target,
triage performance, LWBS, 28-day readmissions, and patient flow.**

[![ED Performance Dashboard](https://raw.githubusercontent.com/liuyizhou0402/data-analysis/main/healthcare-ed-analytics/dashboard/ed_performance_dashboard.png)](https://github.com/liuyizhou0402/data-analysis/tree/main/healthcare-ed-analytics)

**Data → SQL → Dashboard → Recommendations.** Headline insight: the sickest
patients (triage 1) meet the 4-hour target only **53%** of the time vs 99% for
non-urgent — a clinical-risk signal hidden by the blended 90% KPI.
